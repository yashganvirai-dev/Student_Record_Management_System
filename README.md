# Student Record Management System

A beginner-friendly Python CRUD project created for Module 2 of a Python internship.

## Features

- Add student
- View all students
- Search student by ID
- Update student
- Delete student
- CSV file handling
- JSON file handling
- Functions and parameters
- Lambda/list-comprehension concepts can be extended
- Exception handling with try-except
- Simple command-line interface

## Technologies

- Python 3
- CSV
- JSON

## How to Run

1. Install Python 3.
2. Open this project folder in VS Code.
3. Open the terminal.
4. Create a virtual environment:

```bash
python -m venv venv
```

5. Activate it on Windows:

```bash
venv\Scripts\activate
```

6. Run:

```bash
python main.py
```
